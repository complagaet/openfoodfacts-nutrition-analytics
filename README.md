# Open Food Facts: Nutrition and Product Analytics

Итоговый проект №43 по дисциплине **Programming for Data Analysis and Database**.
Кластер 8: **Large-Scale Data Processing (Pandas, Polars, Dask, Parquet)**.

Цель — исследовать пищевую ценность, Nutri-Score и состав продуктов из Open Food Facts,
сравнить способы обработки большого набора данных и обосновать результаты измерениями.

## Текущий этап

**Подготовка и оценка требований, 11 ноября 2026 года.**
По указанию пользователя реализация задания ещё не начата. Сейчас выполняются только
разбор исходного документа, определение границ проекта и подготовка Git-репозитория.
Данные не скачаны, зависимости не установлены, код, SQL и модели не реализованы,
экспериментальные результаты отсутствуют. Инструкция запуска и `requirements.txt`
будут добавлены вместе с реализацией и проверены на рабочем окружении.

## Источник задания

Пользователь предоставил файл `Темы_финальных_проектов_AI.docx` и явно выбрал тему №43.
Содержание файла рассматривается как спецификация учебного проекта. Переход к
реализации определяется отдельным указанием пользователя.

Основной источник данных: [Open Food Facts](https://world.openfoodfacts.org/data).
Числа «3M+ продуктов» и «200+ столбцов» приведены в задании; фактический объём и
схему выбранного снимка предстоит проверить на этапе работы с данными.
