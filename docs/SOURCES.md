## Что проверить при выборе снимка позднее

1. Доступность, формат, разделитель, кодировку и схему; имена полей читать
   из заголовка, не полагаться на позиции столбцов из старых описаний.
2. URL и окончательный URL после redirect, дату получения, размер, hash,
   ревизию источника для Parquet/Hugging Face, если она доступна.
3. Число записей, уникальных продуктов и столбцов; реальную ширину после
   обоснованного разворачивания вложенных структур.
4. Внутренние даты создания/изменения продуктов и свежесть содержимого.
   Один HTTP Last-Modified этого не подтверждает.
5. Наличие версии Nutri-Score, целевой метки и исходных полей для правила;
   доли неизвестных, неприменимых и неполных записей.
6. Нутриенты, единицы, основную базу измерения, страны/категории и доступность
   информации об ингредиентах. Пропуски не подменять нулями.
7. Локальный бюджет памяти/диска и возможность воспроизведения обработки.
